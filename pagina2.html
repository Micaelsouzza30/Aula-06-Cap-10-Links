Model (Modelo) no MVC

O Model representa os dados do sistema. Ele cuida das regras e da comunicacao com o banco de dados.

Principais funcoes do Model

  • Armazena os dados.
  • Executa regras de negocios.
  • Trabalha com o banco de dados.

Exemplo

Um sistema de usuarios pode guardar nome, email e senha. O Model cuida dessas informacoes.
