View e Controller no MVC

View (Visao)

A View mostra os dados do sistema para o usuario. Ela apresenta as informacoes de forma simples e organizada.

Controller (Controlador)

O Controller recebe as acoes do usuario, processa os dados e faz a comunicacao com o Model.

Exemplo

Quando um usuario preenche um formulario e clica em Enviar, o Controller recebe os dados e a View mostra o resultado.
