Introducao ao MVC

O MVC (Model-View-Controller) e uma arquitetura usada no desenvolvimento de aplicacoes para separar os dados, a interface e o controle do sistema.

Componentes do MVC

  • Model - Representa os dados e a logica do sistema.
  • View - Mostra as informacoes para o usuario.
  • Controller - Faz a comunicacao entre Model e View.
